# 실습 D: 방명록 미니 웹 (Guestbook Mini Web)

간단한 이름과 짧은 메시지를 남길 수 있는 순수 웹 프론트엔드(Vanilla HTML/CSS/JS) 기반의 미니 방명록 애플리케이션입니다.

## 📌 주요 기능
- **방명록 등록**: 이름(작성자)과 메시지를 입력하여 새로운 방명록 등록
- **방명록 삭제**: 등록된 글 중 원하는 글을 선택하여 삭제 (확인 팝업 제공)
- **로컬 스토리지 연동**: `localStorage`를 사용하여 브라우저 새로고침이나 재접속 시에도 데이터 영구 유지
- **실시간 글자 수 카운터**: 메시지 입력 시 실시간으로 글자 수 표시 (최대 200자)
- **보안 강화**: DOM 조작 시 `textContent`를 사용하여 XSS(크로스 사이트 스크립팅) 공격 방지
- **무서버(Serverless) 구현**: 데이터베이스나 외부 백엔드 서버 없이 브라우저 환경에서 100% 동작

## 📁 파일 구조
```
├── index.html   # 방명록 웹 페이지 마크업
├── style.css    # 반응형 카드형 UI 디자인 및 스타일링
├── app.js       # 로컬스토리지 연동, 등록 및 삭제 이벤트 처리 로직
└── README.md    # 프로젝트 설명 문서
```

## 🚀 실행 방법
별도의 웹 서버나 설치 과정 없이 브라우저에서 바로 실행할 수 있습니다.
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 엽니다.
